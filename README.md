# 🦆 DuckyHub!

DuckyHub is a little website I created while bored, to showcase my projects, my interests, and most importantly, my uncensored personality, being more than a portfolio but an insight into my life, my future and myself.

It features many things about me like my love for ducks, the topics I'm interested in: Software, electronics, Mathematics etc. and includes some cool easter eggs to keep viewers interested. It also features an amazing and engaging aesthetic layout perfect for maintaining user attention.

**Features:**

    🦆 Love for Ducks!
    
    🤫 Many Easter Eggs to explore
    
    🏆️ Achievements to Collect
    
    📖 List of all my projects with github project link
    
    ℹ️ Database implementation w/ MongoDB for visitor count +
